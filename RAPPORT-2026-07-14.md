### 3. Signature électronique
- Signature « simple » à **valeur légale** (article 1367 du Code civil, règlement eIDAS), intégrée à l'espace client — sans coût ni prestataire externe.
- Affichage du **contrat / mandat** avant signature.
- **Consentement explicite** : contrat, CGV, confidentialité, renonciation au droit de rétractation (4 cases obligatoires).
- Signature dessinée, bloquée tant que les 4 cases ne sont pas cochées.
- **Preuve** : horodatage + adresse IP réelle + navigateur + consentements.
- **Copie signée par email** au client, avec copie à l'administration.
- Conservation prévue **5 ans minimum**.

## ⚠️ À faire avant la mise en production

Le code est prêt mais reste **silencieux** tant que ces éléments ne sont pas en place (comportement voulu). Rien ici ne demande de développement supplémentaire.

1. **Variables d'environnement** — `STRIPE_SECRET_KEY`, `STRIPE_WEBHOOK_SECRET`, `NEXT_PUBLIC_SITE_URL`, `SUPABASE_SERVICE_ROLE_KEY`, `GMAIL_USER`, `GMAIL_APP_PASSWORD` (dans `.env.local` et sur Vercel).
2. **Webhook Stripe** — tableau de bord Stripe → endpoint vers `…/api/stripe/webhook`, événement `checkout.session.completed`, puis copier le secret `whsec_…`.
3. **Migration signature** — exécuter `0005_signature_consent.sql` dans le SQL Editor Supabase (sinon l'enregistrement des signatures échoue).
4. **Contrat réel** — remplacer le mandat générique par le vrai contrat du client (`ContractSignature.tsx`).
5. **Redéployer + rafraîchir** — après déploiement du dernier commit, recharger avec `Ctrl+Shift+R` pour voir le correctif de l'agenda (la page d'accueil est mise en cache).

## 🚀 Évolutions possibles
- **Signature certifiée eIDAS** (Yousign / DocuSign) — signature « avancée / qualifiée », plus robuste juridiquement. Payant, nécessite un compte + clé API du prestataire.
- **Vérification par code (OTP)** par email ou SMS avant la signature, pour renforcer la preuve d'identité.
- **App mobile « Objectif Civique »** — elle appellera **le même backend** pour le paiement ; rien à redévelopper côté serveur, seule la clé publique est utilisée côté app.
